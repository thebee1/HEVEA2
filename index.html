✅ Rôle de ce site

Ce site valide les identifiants envoyés par l'application HEVEA1. Il ne redirige jamais. Il communique via postMessage.

🔌 API exposée

Actions acceptées (via postMessage) :

{
  action: "login",
  email: "user@example.com",
  password: "••••••••",
  requestId: "unique-id"
}

// Réponse :
{
  ok: true,
  token: "eyJ...",
  user: { email, role, name },
  requestId: "unique-id"
}
